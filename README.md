# 商業創意產生器

輸入一個關鍵字，系統隨機抽出另一個名詞，把兩者結合成一個商業創意——含創意名稱、描述與逐步打造步驟，再用**市場需求／收益性／競爭優勢／可擴展性／社會影響**五個構面各自五分制評分＋具體理由＋總平均分數。

## 特色

- 🎲 內建 76 個名詞的隨機名詞庫，涵蓋動物／科技／自然／職業／日常物品／抽象概念／場所／奇幻等 8 大類
- ⚙️ 免 API 金鑰即可使用（規則式示範版本，同一組關鍵字必定產出同樣結果）
- 🤖 選用串接 Claude／OpenAI／Gemini／OpenRouter（BYOK，自備金鑰）取得更貼切的 AI 生成內容與評分理由
- 📊 五構面評分＋SVG 健檢儀表呈現總平均分數（前端自行計算，不採信 AI 回傳的總分）
- 📱 響應式設計，手機／平板／桌面皆可使用

## 使用方式

直接開啟 `index.html`，或用任意靜態伺服器託管本資料夾即可，無需安裝、無需建置步驟。

```bash
python -m http.server 8801 --directory .
```
